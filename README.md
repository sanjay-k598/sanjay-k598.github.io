# Sanjay CloudOps Portfolio (Static)

Dark, animated portfolio with a hero background image.

**Architecture & Tools Used:** Built using **HTML, CSS, and JavaScript**, hosted on **GitHub Pages**, and automatically deployable via **GitHub Actions** following DevOps automation principles.

## Deploy
1. Use the repository `sanjay-k598.github.io`.
2. Upload all files at the root (keep the folders as-is).
3. In **Settings → Pages**, choose **Deploy from a branch → main / root**.
