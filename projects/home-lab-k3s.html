My Kubernetes Homelab Setup (k3s)

This page documents my Kubernetes homelab setup end to end: hardware, network, cluster bootstrap, GitOps workflows, and the apps I run. I built it to practice production patterns in a small environment.

k3s Argo CD GitOps Ingress Observability TLS

1) Architecture overview

Goal: reproducible cluster setup with GitOps. All workloads are deployed from Git, not by clicking in UIs.

  • Cluster: k3s multi-node
  • GitOps: Argo CD
  • Ingress: (Traefik or NGINX, whichever you use)
  • Certs: cert-manager (optional)
  • Storage: (Longhorn / local-path / NFS, whichever you use)
  • Observability: (Prometheus/Grafana/Loki, if used)

4) Cluster bootstrap (k3s)

High level steps I followed:

  1. Prep OS and dependencies on all nodes
  2. Install k3s server (control plane)
  3. Join worker nodes with token
  4. Confirm node readiness and core system pods
Commands (example placeholders) 
# Control plane
curl -sfL https://get.k3s.io | sh -

# Get node token
sudo cat /var/lib/rancher/k3s/server/node-token

# Worker
curl -sfL https://get.k3s.io | K3S_URL="https://<cp-ip>:6443" K3S_TOKEN="<token>" sh -

# Verify
kubectl get nodes -o wide
kubectl get pods -A

7) Step-by-step runbook

This is the exact sequence I would follow to rebuild the cluster from scratch. Keep it short and repeatable.

  1. Provision nodes, update OS, set hostnames
  2. Install k3s control plane
  3. Join workers
  4. Install Argo CD
  5. Point Argo CD to GitOps repo
  6. Install ingress, storage, cert-manager
  7. Deploy apps
  8. Validate and document URLs
