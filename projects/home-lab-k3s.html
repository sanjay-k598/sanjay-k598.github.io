My Kubernetes Homelab Setup

This page documents my Kubernetes homelab setup end to end: hardware, networking, cluster bootstrap, GitOps workflows, and the workloads I run. The goal was to simulate production-style patterns in a small controlled environment :)

1) Architecture overview

Goal: reproducible cluster setup using GitOps. All workloads are deployed from Git, not manually applied.

  • Cluster: k3s multi-node on Dell servers
  • GitOps: Argo CD
  • Ingress: Traefik
  • Load Balancer: MetalLB
  • TLS: cert-manager + Let's Encrypt
  • Storage: local-path
  • Observability: Prometheus & Grafana

End-to-end request flow: User → Router → MetalLB → Traefik → k3s cluster → Applications. GitOps sync: Argo CD continuously reconciles cluster state from Git.

3) Network

  • Router/Firewall: MikroTik
  • Load Balancer: MetalLB (Layer 2 mode)
  • Ingress IP: Dedicated LAN VIP
  • Domain: Internal wildcard domain mapped to cluster VIP

4) GitOps Workflow

  • Git repository stores all manifests
  • Argo CD watches and auto-syncs changes
  • Declarative cluster state maintained

5) Observability

  • Prometheus for metrics collection
  • Grafana dashboards for visualization
  • Node and pod-level monitoring enabled

6) Lessons Learned

  • GitOps eliminates configuration drift
  • MetalLB simplifies bare-metal load balancing
  • Ingress separation keeps routing clean
  • Observability is critical even in small clusters
